## ❓ Зачем понадобится твой сервер (он очень простенький)?

1. **Защита API-ключа:**
   - На бесплатном хостинге (GitHub Pages / Vercel / Netlify) весь код выполняется в браузере пользователя.
   - Если поместить твой ключ `h1_1d1143a847d92c07474605f2464115085bca3e9da3daba37` напрямую в фронтенд, любой человек сможет нажать `F12` и украсть его.
   - **Твой сервер хранит ключ внутри себя** и никогда не передает его наружу.
2. **Обход CORS:**
   - Браузеры блокируют прямые сетевые запросы к API из-за политики Cross-Origin Resource Sharing. Сервер отправляет запросы без этих ограничений.
3. **Минимальные требования к серверу:**
   - Серверу не нужны терабайты памяти или мощные видеокарты: он работает как легкий **асинхронный мост (прокси)**. Ему достаточно 512 МБ или даже 256 МБ RAM!
4. **Контроль и сессии:**
   - Ты сможешь ограничить доступ по токену (`UUSULXFDQWP4FBHTH4MKYSCETTSOHZSB`), чтобы чужие люди не тратили твои токены Claude.

## 🚀 Как запустить сервер на твоем H1:

```bash
# 1. Загрузи server.py на свой сервер
# 2. Запусти одной командой (не требует pip install):
python3 server.py
```

Для работы в фоновом режиме 24/7:
```bash
nohup python3 server.py > server.log 2>&1 &
```
